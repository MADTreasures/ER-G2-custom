# Entwürfe aus dem Baukasten

Hier liegen Entwürfe aus dem G2 Baukasten ([`../designer/`](../designer/README.md)) im Format
`g2-baukasten@1`: ein Projekt mit Seiten, jede Seite ein Stapel aus Bausteinen (Überschrift, Text,
Knopf, Liste, Schalter, Wert, Fortschritt, Trennlinie) plus einer Notiz, was sie tun soll.

- `beispiel.json` – das Beispielprojekt (Start, Einkaufsliste, Einstellungen).
- Eigene Entwürfe: im Baukasten „Für den Chat kopieren“ und als `.json` hier ablegen.
